# Chrome-расширение: карточки из YouTube

Расширение живёт в иконке на панели Chrome. По клику всплывает окно поверх страницы (попап) с теми же настройками режима, что в диалоге приложения (Слова / Фразы / Слова+фразы / Предложения), превью с галочками и сохранением в облачный аккаунт на [kar-tochki.pages.dev](https://kar-tochki.pages.dev).

Своей кнопки на странице YouTube расширение не рисует: она перекрывала интерфейс плеера. Ссылку на текущий ролик content script передаёт в фоне сам.

## Установка (unpacked)

1. Скачайте репозиторий. Собранный `extension/dist/*.js` хранится в git, поэтому отдельная сборка для установки не нужна. Если правите `extension/src/`, пересоберите и закоммитьте `dist` вместе с исходником:

```bash
npm install
npm run ext:build
```

2. Откройте Chrome → `chrome://extensions` → включите **Developer mode**.
3. **Load unpacked** → выберите папку `extension/` (не `extension/src`).
4. На [kar-tochki.pages.dev](https://kar-tochki.pages.dev/?ext_connect=1) войдите в облачный аккаунт (если ещё не вошли). Баннер подтвердит подключение.
5. Откройте любое видео на YouTube → нажмите иконку КАР-точки на панели Chrome → выберите режим и папку → **Сформировать** / **Generate** → отметьте карточки → **Создать**.

UI расширения: **русский или английский** (язык интерфейса Chrome / `navigator.language`).

> Попап закрывается по клику мимо него, и вместе с ним обрывается текущая операция. Пока идёт расшифровка (до трёх минут) окно лучше не закрывать; если закрыли — нажмите иконку снова и повторите генерацию.

## Privacy

Для Chrome Web Store и пользователей: [extension-privacy.md](./extension-privacy.md).

## Что нужно заранее

- Облачный аккаунт на прод-инстансе.
- Хотя бы одна обычная папка (не vocab-pack).
- **Supadata API ключ** в Настройки → «Карточки из YouTube» → «Настроить» (как в веб-приложении).
- Ролик до **20 минут**, с доступными субтитрами.

## Ограничения v1

- Chrome MV3. По умолчанию origin — `https://kar-tochki.pages.dev`.
- Self-host: `KAR_EXT_APP_ORIGIN=https://your.domain npm run ext:build` (переписывает `manifest.json` и бандл).
- Нет импорта `.srt` / `.vtt` из расширения (только текущий ролик).
- Нужен интернет; офлайн-очередь SyncQueue не используется.
- Публикация в Chrome Web Store — отдельно; privacy policy готова, listing/screenshots — следующий шаг.

## Структура

| Путь | Назначение |
|---|---|
| `extension/manifest.json` | MV3 манифест |
| `extension/src/` | исходники (background, content scripts, окно расширения) |
| `extension/dist/` | сборка (`npm run ext:build`) |
| `js/lib/ext-connect.ts` | bridge `?ext_connect=1` в PWA |

## Отключение

В окне расширения → **Отключить** (чистит сессию в `chrome.storage`). Либо удалите расширение в `chrome://extensions`.
