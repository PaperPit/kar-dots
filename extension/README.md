# КАР-точки — Chrome-расширение

Иконка расширения на панели Chrome → всплывающее окно поверх страницы →
карточки в аккаунт на [kar-tochki.pages.dev](https://kar-tochki.pages.dev).

Полная инструкция: [docs/chrome-extension.md](../docs/chrome-extension.md).

## Установка

```bash
# Chrome → chrome://extensions → включить «Режим разработчика»
#        → «Загрузить распакованное расширение» → выбрать папку extension/
```

Собранный `extension/dist/*.js` лежит в git, поэтому после `git clone` или
`git pull` расширение грузится сразу, без сборки. Sourcemaps (`*.map`) не
хранятся — они нужны только при отладке локальной сборки.

Меняли что-то в `extension/src/` — пересоберите и закоммитьте `dist` вместе с
исходником, иначе Chrome продолжит выполнять старый бандл:

```bash
npm install
npm run ext:build
# затем chrome://extensions → «Обновить» у КАР-точек
```

## Как пользоваться

1. Открой ролик на YouTube.
2. Нажми иконку КАР-точки на панели Chrome — окно всплывёт под иконкой поверх
   страницы. Отдельной кнопки на самой странице YouTube нет: она перекрывала
   интерфейс плеера, поэтому убрана.
3. В окне: «Войти через КАР-точки» → выбрать папку и режим → «Сформировать».

Попап закрывается по клику мимо него — вместе с ним обрывается и текущая
операция. Расшифровка ролика идёт до трёх минут, всё это время окно должно
оставаться открытым.

Ключи Supadata и Gemini/Groq расширение берёт из настроек аккаунта
(КАР-точки → Настройки → «Карточки из YouTube»), своих не хранит.

## Частые проблемы

**«Cannot load extension with file or directory name _…»** — Chrome не грузит
распакованные расширения, если где-то внутри папки есть файл или каталог,
имя которого начинается с `_`. Убери его за пределы `extension/`.

**«Extension context invalidated»** в консоли YouTube — так выглядит старый
content script на уже открытой вкладке после перезагрузки расширения. Сейчас
скрипт замечает это и молча выключается; достаточно обновить вкладку.

**«Не удалось достучаться до https://kar-tochki.pages.dev»** — запрос к API не
ушёл вовсе. Проверь интернет, VPN, антивирус и блокировщик рекламы. Если
сервер ответил, но с ошибкой, окно покажет текст именно от сервера.

**Окно открывается пустым** — значит упал старт скрипта. Правый клик по окну
расширения → «Просмотреть код» → вкладка Console: там будет реальная ошибка.
